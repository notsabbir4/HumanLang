# Rules from the project owner

- Do not update old games or projects (games/, examples) when HumanLang changes. Only when the owner says so. (Set 2026-11-09.)
- Each game in games/index.json has a "version" (the HL version it was made with); the Games page groups by it.
- Releases: small 0.3.1 -> 0.3.1.1, big -> 0.3.2, massive -> 0.4.1. The owner publishes the release tag.

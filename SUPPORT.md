# Getting help

- **Learning HL?** Start with the Tutorial. Stuck on an error? Read its first line and the line it shows; most mistakes are typos.
- **Question or "how do I...?"** Ask in Discussions (category: Help) or the chat room. Paste your program and the full error message.
- **Found a bug?** Open an issue using the "Bug report" form.
- **Something confusing, even if it works?** Use the "Beginner feedback" form. Confusing messages are bugs in HL, not in you.
- **Want a new feature?** See `docs/proposals/README.md`.

# HumanLang for VS Code

Support for [HumanLang](https://github.com/notsabbir4/HumanLang) (`.hum` files):

- colours (syntax highlighting) and snippets
- live error messages and completion, using the `hl` program
- a **Run** button (the little triangle at the top right) and **Ctrl+F5** to run the open file

You need HumanLang installed for the live errors and the Run button:
<https://notsabbir4.github.io/HumanLang/install.html>

Step-by-step guide: <https://notsabbir4.github.io/HumanLang/editors.html>

# Games and projects

Every game has a `version` in `index.json`: the HumanLang version it was made with. The Games page groups games by it.

**Rule (from the project owner, 2026-11-09):** when HumanLang gets a significant change or update, do NOT update the older
games or projects to match. They stay as they were made. Only update an old game when the owner says so.
Games already changed before this rule are left as they are.
